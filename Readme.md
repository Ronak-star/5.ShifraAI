# Shifra AI

**Add a Virtual Assistant to your website.**

Shifra AI lets you create a smart, voice-enabled assistant that talks to your website visitors, answers their questions, and helps them navigate your site instantly — no coding required.

🔗 Live demo: [5-shifra-ai.vercel.app](https://5-shifra-ai.vercel.app)

---

## ✨ Features

- 🎙️ **Voice AI for modern websites** — visitors can tap a button and speak instead of typing.
- 🤖 **Instant answers** — the assistant responds to questions about your website in real time.
- 🎨 **Customizable widget** — choose from multiple color themes (dark, light, gray, green, etc.) to match your brand.
- 🛠️ **No-code Builder** — configure and preview your assistant from a simple dashboard.
- 💳 **Billing dashboard** — manage your plan and usage.
- 🆓 **Free plan** — includes 200 AI responses to get started.

## ⚙️ Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+ recommended)
- npm or yarn

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/Ronak-star/5.ShifraAI.git
   cd 5.ShifraAI
   ```

2. Install dependencies for both Client and Server
   ```bash
   cd Client
   npm install

   cd ../Server
   npm install
   ```

3. Set up environment variables
   Create a `.env` file in the `Server` directory with any required keys (e.g. API keys, database URL, etc.)

4. Run the Server
   ```bash
   cd Server
   npm start
   ```

5. Run the Client
   ```bash
   cd Client
   npm run dev
   ```

6. Open the app in your browser at the URL shown in the terminal (e.g. `http://localhost:5173`)

## 📖 Usage

1. Sign in to your account.
2. Go to the **Builder** tab to configure your virtual assistant (name, colors, behavior).
3. Preview the assistant widget live on the page.
4. Copy the generated embed snippet into your website.
5. Track your usage and manage your subscription from the **Billing** tab.
